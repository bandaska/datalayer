# Server-Side GTM: proč a jak začít

Server-Side Google Tag Manager posouvá měření z prohlížeče na server.
Získáte přesnější data, rychlejší web a odolnější first-party měření, vždy v souladu se souhlasem návštěvníka.

## Proč server-side

Klientské měření naráží na limity prohlížečů, blokátory reklam a omezení cookies v Safari a Firefoxu.
Přesunem zpracování na server získáte kontrolu nad daty.

javascript
Kopírovat

```
dataLayer.push({
  event: 'purchase',
  ecommerce: { transaction_id: 'T123', value: 1290 }
});
```

### Shrnutí

Server-side měření je dnes standard pro datově řízené e-shopy.
