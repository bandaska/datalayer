PROČ HEUREKA PŘES SERVER-SIDE

## Co server-side dělá pro Heureku

### Ověřeno zákazníky bez iframe

Heureka pixel běží jako iframe a 25 % CZ zákazníků ho má v ad-blockeru. Server-side proxy pošle conversion event z naší domény — neblokovatelné.

### First-party Heureka feed

Generujeme Heureka XML feed s vašimi produkty na first-party doméně (např. <code>feed.eshop.cz/heureka.xml</code>). Heureka.cz se neptá na CDN, čte přímo z vás.

### Recenze automaticky

Po purchase eventu pošleme "Ověřeno zákazníky" trigger automaticky. Heureka pošle email zákazníkovi 5 dní po nákupu — vy už nic nemusíte konfigurovat.

### Vše v ceně

Heureka v jednom plánu s GA4, Meta CAPI, Sklikem, TikTokem a 14 dalšími. Bez per-pixel poplatků.

SETUP

## Tři kroky a data tečou.

1. 1

   ### Registrace + GTM container

   14 dní zdarma. Setup wizard má Heureka tag připravený pro Shoptet / Upgates / FastCentrik.
2. 2

   ### Heureka API klíč

   Z Heureka administrace → API → vytvořte klíč pro "Ověřeno zákazníky". Vložte ho v `/dashboard/platforms/heureka/` a my pošleme conversion eventy automaticky.
3. 3

   ### Feed URL pro Heureku

   Generujeme `feed.eshop.cz/heureka.xml` z vašich produktových dat (ručně nebo z CSV / API). V Heureka admin → Marketing → Heureka shopping vložíte naši URL.

FAQ

## Časté otázky

Heureka nemá oficiální CAPI / Conversions API. Jak to děláte?
+

Heureka má dvě cesty: conversion pixel (iframe blokovatelný) a server-side conversion endpoint dostupný přes API klíč. Voláme S2S endpoint s order ID, value a transaction parametry.



Generujete celý Heureka feed?
+

Ano — buď z product CSV uploadu, nebo z přímého API vašeho e-shopu. Cache na 1 hodinu, automatický refresh. Heureka feed je validovaný proti aktuální XSD.



Funguje to s Heureka Plus?
+

Ano, Heureka Plus používá stejný conversion endpoint i feed formát. Posíláme oba typy eventů s rozlišením v parametru.



A Heureka.sk?
+

Plně podporujeme Heureka.sk paralelně. Stejný API klíč, jen jiná lokalizace feedu (EUR, sk-SK).



Kolik platím za Heureka tracking?
+

Heureka je v každém DataNostro plánu — od 349 Kč / měsíc (STARTER) máte Heureku, Sklik, GA4, Meta CAPI a 14 dalších platforem bez per-pixel příplatků.
