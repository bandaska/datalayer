# Více konverzí, *čistší* data, klidnější noci.

Server-side tracking, který obchází ad-blockery, prodlužuje životnost cookies a vrací konverze, které vám právě teď utíkají. Postaveno pro český trh — Sklik, Heureka, faktury v Kč, podpora v češtině.

VÝSLEDKY

## Co se reálně *změní*, když nasadíte DataNostro.

+20–35 %

### Match rate na Meta

Server-side eventy do Meta CAPI mají vyšší shodu s Facebook profily — pošlete víc parametrů (hashed email, telefon, fbp). Konverze, audience i optimalizace se zlepší během dnů.

Typický rozsah dle Meta CAPI benchmark (2024); konkrétní výsledek závisí na kvalitě user dat a katalogu.

+25–40 %

### Vidíte traffic, který GA4 ztrácí

Část uživatelů má ad-blocker nebo aggressive ITP. Server-side request odchází přímo z vaší domény — neblokovaný, atribuovaný, započítaný.

Rozsah dle veřejných měření (Stape, Simo Ahava); publikum s vyšším podílem iOS a tech-savvy uživatelů je na horní hranici.

2 roky

### Cookie life místo 7 dnů

Safari ITP řeže first-party cookies na 7 dní. Cookie Keeper sGTM Power-Up je rotuje server-side — atribuce a remarketing přežijí celé sezony.

5 min

### Setup, ne týdny DevOps

Vyplníte GA4 Measurement ID, přidáte CNAME u svého DNS registrátora a server-side běží. Bez vlastní GCP konzole, bez Cloud Run, bez Dockeru.

## Všechny platformy. Všechny *Power-Upy*. Bez příplatků.

### GA4

Server-side Measurement Protocol. Bot detection a anti-spam zabudované.

### Meta CAPI

Conversions API přes server-side. Hashed PII, deduplikace event\_id, vyšší match rate.

### Google Ads

Enhanced conversions, gclid restoration, customer match audiences server-side.

### TikTok Events

Events API 2.0, ttclid restoration, advanced matching pro lepší attribuci.

### Sklik (Seznam)

Conversion API pro Sklik nativně — bez custom HTTP request stavění.

### Heureka

Měření konverzí a Ověřeno zákazníky integrace přímo v platformě.

### Anti-tracking bypass

Custom Loader (vlastní doména), Cookie Keeper (anti-ITP), Bot Detection.

### GEO Enrichment

MaxMind GeoIP — Country/Region/City do každého server-side eventu, bez dalších licencí.
