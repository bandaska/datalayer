## O CSS Programu v otázkách a odpovědích

### Co je CSS Program? [1]

[1]

CSS Program je reakcí Google na rozhodnutí Evropské komise, která požaduje, aby Google ve výsledcích vyhledávání poskytoval ostatním srovnávačům zboží stejný prostor jako své službě Google Nákupy.

Díky programu teď můžete získat slevu až 20 % z CPC v Google Nákupech.

### Jak celý program funguje? [2]

[2]

Náš český a slovenský zbožový srovnávač [permoniq.com/cs/shop/ a permoniq.com/sk/shop/] jako Google CSS Partner dostane slevu až 20 % z CPC, aby mohl v Google Nákupech vstupovat do aukce spolu s CSS Google. Pro vás to znamená, že těch až 20 % můžete buď ušetřit, nebo dále investovat a získat více prokliků do vašeho e-shopu.

### Jaké změny přinese zapojení do CSS Programu [Advisio]? [3]

[3]

Změní se pouze označení CSS partnera pod jednotlivými produkty. Místo z webu Google bude u vašich produktů uvedeno z webu permoniq.com/cs/shop/ nebo v případě Slovenska permoniq.com/sk/shop/. Proklik z produktu vede přímo na váš web. Na principu inzerce se nic nemění. Pokud u nás nemáte PPC kampaně, zůstanou nadále ve vaší správě a my k nim nebudeme mít přístup.
