# Weby na míru, které se načtou dřív, než zákazník zaváhá

Stavím rychlé weby pro živnostníky a malé firmy. Žádné šablony z katalogu – web navržený kolem toho, co prodáváte a komu.

## Co dostanete

* **Web navržený na míru** – vzhled i struktura vychází z vašeho oboru a zákazníků.
* **Rychlé načítání** – web bez zbytečného nepořádku, navržený s ohledem na Core Web Vitals i pohodlí návštěvníků.
* **SEO základ v ceně** – meta tagy, Open Graph, strukturovaná data schema.org, sitemap i robots.txt.
* **Měření od začátku** – GA4 přes Tag Manager s Consent Mode v2, takže od spuštění víte, co web přináší.
* **Srozumitelné texty** – pomohu vám je napsat tak, aby zákazník hned pochopil, co nabízíte a proč se má ozvat.
* **Předání a zaškolení** – vysvětlím, jak web funguje a jak číst jeho čísla.

## Pro koho weby stavím

Nejčastěji pro menší firmy a živnostníky, kteří potřebují důvěryhodnou a funkční prezentaci: kadeřnictví, řemeslníky, ubytování, poradce a osobní značky. Ukázky najdete [v portfoliu](/#portfolio) – každý z těch webů dnes reálně slouží zákazníkům.

## Jak spolupráce probíhá a jak vzniká cena

Začneme krátkou konzultací zdarma: co děláte, kdo jsou vaši zákazníci a co má web splnit. Dostanete pevnou cenu podle dohodnutého rozsahu. Bez předchozí dohody ji nepřekročím. Pak navrhnu strukturu a vzhled, společně doladíme texty a web spustíme. Jednostránkový web bývá hotový přibližně za dva týdny od zahájení, vícestránkový za čtyři – podle rozsahu a dodání podkladů. Konkrétní cenová pásma podle rozsahu najdete na stránce [Kolik stojí web na míru](/kolik-stoji-web.html).
