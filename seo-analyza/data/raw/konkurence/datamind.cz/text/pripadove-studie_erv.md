# **Datový sklad pro řízení** a reporting on‑premise ERGO cestovní pojišťovna

ERGO cestovní pojišťovna je největší cestovní pojišťovna v České republice. Každý rok pojistí více než 1,6 mil. klientů a spolupracuje přibližně se 79 tisíci smluvními zdravotnickými zařízeními po celém světě.   
Data Mind pomohl ERGO cestovní pojišťovně vybudovat centrální datový sklad, který sjednotil data z interních systémů a vytvořil spolehlivý základ pro management reporting a analytiku.

### Procesy a integrace dat

automatizovaný sběr, transformace a načítání dat

### Datové sklady a Data Lake

centralizovaná správa firemních dat

### Přechod do cloudu

implementace datových řešení na Microsoft Azure

### Datové modelování a analýza

optimalizace výkonu a struktury dat

### Automatizace datových procesů

ETL/ELT pipeline, pravidelná aktualizace, minimum manuální práce

## Kontext projektu

ERGO potřebovala vytvořit **centrální datový sklad**, který by fungoval jako **jednotný zdroj pravdy** pro reporting a analytiku.

Podpora pro:

* plánování a controlling (KPI, rozpočet, predikce)
* obchod a partnerskou spolupráci
* operativu a řešení klientských situací
* interní i regulatorní reporting

## Hlavní výzvy

Projekt musel vyřešit několik klíčových oblastí:

**Integrace dat z komplexních systémů**  
Data bylo nutné sjednotit z více interních zdrojů.

**Jednotné definice metrik**  
Bylo potřeba harmonizovat KPI napříč organizací.

**Auditovatelnost dat**  
Systém musel zajistit konzistenci a dohledatelnost dat.

**100 % on-premise provoz**  
Kvůli regulatorním požadavkům.

## Řešení

Data Mind navrhlo datový sklad postavený čistě na **Microsoft stacku**.

Projekt postupoval od návrhu datového modelu přes implementaci datových toků až po rychlé dodání prvních reportů. Platforma byla navržena tak, aby bylo možné postupně rozšiřovat další analytické agendy.

## Výsledek

Bylo vytvořeno **15 komplexních dashboardů** pro klíčové oblasti řízení společnosti.

Datový sklad dnes zpracovává **stovky GB dat** a poskytuje stabilní základ pro analytiku i další rozvoj datové platformy.

## Použité technologie

* Microsoft SQL Server
* SQL Server Integration Services (SSIS)
* SQL Server Reporting Services (SSRS)

Celé řešení běží **plně on-premise v Microsoft ekosystému**.

## Přínosy

Nový datový model dal interním uživatelům **jednotný základ pro práci s daty** a umožnil vytvářet **ad-hoc reporty a analýzy bez závislosti na dodavatelích** provozních systémů.  
Data jsou nyní **validovaná, konzistentní a připravená pro audity i regulatorní požadavky**. Reporting je díky tomu rychlý, stabilní a snadno rozšiřitelný, takže může růst spolu s potřebami celé organizace.
